# igornunesfontoura.github.io

Meu portfólio pessoal, com visual inspirado em terminal Linux: as seções são pastas que você abre clicando ou digitando comandos (`ls`, `cd`, `cat`, `help`).

**Acesse:** https://igornunesfontoura.github.io

Feito com HTML, CSS e JavaScript puros, sem framework e sem etapa de build. Paleta Tokyo Night e fonte JetBrains Mono.

## Rodar localmente

```sh
python3 -m http.server
```

Depois abra http://localhost:8000.

## Editar o conteúdo

Os textos de cada pasta e arquivo ficam no objeto `raiz`, no começo de [`script.js`](script.js). Para adicionar um projeto, crie uma nova pasta dentro de `projetos` com um `README.md`.
